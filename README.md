# The World in One Day — Tuesday, 24 November 2026

Broadsheet newspaper summing up 24 November 2026 in one image: 31 verified
stories across 6 regions. Three large heroes (Hormuz tankers, Ulleung air-raid
alert, Sanofi's $41B Insmed deal) plus six smaller heroes, a world map with
31 numbered dots at true lon/lat, "THE DAY IN NUMBERS", a UTC timeline and a
DATE CHECK bar. All illustrations are flat-vector drawings made with PIL in
`build.py`; `main.py` copies `entry.png` to the output directory.
